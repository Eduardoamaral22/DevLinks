O DevLinks é uma página pessoal desenvolvida com HTML, CSS e JavaScript, que reúne meus links e permite acessar meu portfólio.

O site possui:

- 🔗 Links para minhas redes e projetos.
- 📁 Portfólio com os trabalhos desenvolvidos.
- 🎨 Interface personalizada utilizando CSS.

🛠️ Tecnologias utilizadas

- HTML5: estrutura das páginas.
- CSS3: estilização e organização visual.
- JavaScript: interatividade e alteração de tema.
- Linguagem C: desenvolvimento de jogos e aplicações.
